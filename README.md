# Plataforma de Micro-crédito Digital 🚀

Este repositório contém uma solução completa para gestão de instituições de micro-crédito, projetada como uma plataforma SaaS Multi-Tenant.

## 📦 Estrutura do Projeto

- **`/backend`**: API REST robusta construída com Node.js, Express e MongoDB. Implementa isolamento de tenants, gestão de créditos, contratos dinâmicos, auditoria e serviços de notificação (SMS/WhatsApp).
- **`/admin-web`**: Painel administrativo premium construído com React. Permite a gestão de clientes, aprovação de créditos, configuração de instituições (Owners), validação de documentos e dashboards de BI.
- **`/mobile-app`**: Aplicação móvel para clientes, construída com React Native (Expo). Permite simulação de crédito, upload seguro de documentos e assinatura digital de contratos.

## 🛠️ Funcionalidades Principais

- **Arquitetura Multi-Tenant**: Um Owner pode gerir múltiplas instituições de forma independente.
- **Fluxo Digital de Contratos**: Geração automática de PDFs e assinatura digital auditada.
- **Gestão de Documentos**: Upload via mobile e portal de validação via web.
- **Comissões e Metas**: Sistema automático de incentivos para agentes de campo.
- **Segurança**: Auditoria completa de ações críticas e proteção de rotas por perfis de acesso.
